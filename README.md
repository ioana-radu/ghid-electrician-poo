# Ghidul Electricianului: Treasure Hunt Educativ

## Descriere Proiect
Proiect dezvoltat pentru cursul de Programare Orientată pe Obiecte (POO). 
Aplicația este un ghid educațional sub formă de vânătoare de comori dedicat noțiunilor de electrotehnică, circuite serie-paralel și teorie electrică.

## Etape Proiect
* **Etapa 1:** Implementarea claselor de bază, încapsulare, constructori, destructori și supraincărcarea operatorilor ("ModulTeoretic").
